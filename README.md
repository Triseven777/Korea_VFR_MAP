# KoreaVFR_v2.01

V2.00 기반 오각형 Leg 배지 수정판.

- 오각형 전체 외곽을 SVG 흰색 테두리로 표시합니다. 화살촉에도 테두리가 이어집니다.
- 내부의 얇은 흰색 테두리를 제거했습니다.
- 첫 줄은 거리(NM), 둘째 줄은 자기방위각(°M)입니다.
- 자기편차 계산 불가 시 MAG UNKNOWN으로 표시합니다.
- 고도 입력과 3D 경로는 유지하며, 고도 변경으로 배지 방위각이 덮어써지지 않습니다.

## 현재 범위
실제 GPS가 아닌 시뮬레이션입니다. 외부 지도·라이브러리는 인터넷에 의존합니다.
경로는 메모리에 저장되며 새로고침 시 초기화됩니다.
