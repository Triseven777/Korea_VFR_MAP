# KoreaVFR_v2.02

## 변경 내용
- Leg 배지 62×30 → 50×24 px, 전체 불투명도 80%.
- 3D에서 Leg 중간 계획고도로 투영하여 마젠타 경로보다 화면상 16px 위에 배치.
- 배지와 겹치는 포인트 설명은 배지 아래로 이동.
- 줌 10 미만에서 배지 숨김. LEG_BADGE_MIN_ZOOM으로 조정 가능.
- 출발·도착 Marker 드래그 잠금. VIA는 이동 가능.
- 출발·도착 기본고도 0 ft. 도착은 앞 고도 변경을 승계하지 않음. 직접 입력 가능.
- 포인트 팝업에 통과고도(FT MSL) 추가. 0~60000 ft 검증 후 경로 정보·3D에 반영.

## 배포
ZIP 내부 index.html, assets, README.md를 GitHub 저장소 루트에 업로드합니다.
별도 빌드는 없습니다. GitHub Pages에서 배포 브랜치와 /(root)를 선택합니다.

시뮬레이션 빌드이며 네트워크 지도 및 메모리 경로를 사용합니다.
실기기 3D 투영·라벨 겹침 검증은 별도 필요합니다.
