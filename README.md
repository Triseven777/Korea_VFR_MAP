# KoreaVFR_v2.07

- 3D 픽스 영역의 지형 깊이 가림을 해제하여 지형이 낮은 면을 뚫고 나오는 시각적 구멍 방지.
- 미입력 상/하단은 각각 0ft AGL 계산. 둘 다 미입력이면 높이 0인 면으로 표시.
- 커튼과 영역의 겹치는 고도 구간에 주황색 상/하단선과 진입/이탈선 표시.
- 고도 입력 픽스의 압정 우측에 상한/하한 표시. AGL 0 및 미입력은 GND.
- 라벨은 viewport 정렬 유지, 줌 10 이하 또는 압정/반경 경계와 충돌하면 숨김.

깊이 가림 해제는 표시 정책이며 실제 지형-영역 충돌 판단이 아닙니다.
교차선은 원의 Mercator 근사와 48구간 샘플링, DEM을 사용합니다.
JS 구문·기본 계산 검증 완료. iPad 3D 시각 검증은 별도 필요합니다.
ZIP 내용물을 GitHub 저장소 루트에 업로드하세요. 임시 메모리 저장 방식은 유지합니다.
