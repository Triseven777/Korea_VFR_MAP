# KoreaVFR_v2.04

- Top View 범위 경계 5pt. 3D에서는 상단면에 주황색 경계, 지표면 1pt 실선.
- 상단 경계는 삼각형 ribbon으로 표시하며 카메라 기울기에 따라 화면 두께가 달라질 수 있습니다.
- 팝업 우상단 ×. 저장 버튼 제거. 팝업 바깥 클릭 또는 ×로 자동 저장 및 설정 모드 해제.
- 유효하지 않은 입력은 오류를 표시하고 팝업을 유지합니다. 신규 기본명 FIX 번호.
- 출발지/경유지/도착지 설정. 경유지는 출발·도착 설정 후 추가 가능합니다.
- 기존 픽스 심볼 탭으로 재편집. 임시 메모리 저장이며 새로고침하면 삭제됩니다.

ZIP 내용물을 GitHub 저장소 루트에 업로드합니다. 실기기 터치·3D 검증은 별도 필요합니다.
