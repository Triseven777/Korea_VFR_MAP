# KoreaVFR_v2.00

V53 기반 수정판. 빌드 없이 GitHub Pages에 배포할 수 있는 정적 웹 앱입니다.

## 배포
1. ZIP을 해제하고 index.html, assets 폴더, README.md를 저장소 루트에 업로드합니다.
2. GitHub 저장소 Settings → Pages에서 배포 브랜치와 /(root)를 선택합니다.
3. 배포된 HTTPS 주소에서 실행합니다. assets 폴더 이름과 파일명을 유지하세요.

## 수정
- 3D 렌더링 실패 시 2D 경로선 유지. 지도 pitch 변경 후에도 유지합니다.
- 계획고도 변경 시 포인트와 Leg 배지 고도를 즉시 갱신합니다. 입력창을 재생성하지 않습니다.
- 자기편차 실패·비정상 값은 UNKNOWN으로 처리하고 방향 표시 및 이동 시뮬레이션을 중지합니다.
- SIM / 가상 위치를 상시 표시하고 위치 복귀 버튼의 설명을 변경합니다.
- 중복 zoom 갱신 이벤트를 제거했습니다.

## 현재 범위
실제 GPS가 아닌 자동 비행 시뮬레이션입니다. 경로는 메모리에만 있으며 새로고침 시 초기화됩니다.
MapLibre, magvar, 위성영상, DEM은 외부 네트워크를 사용합니다. Offline-first 구현은 아직 없습니다.
지도 공급자는 MapLibre + Esri World Imagery + Mapterhorn입니다.
공역·NOTAM·운항제약 등의 신규 기능과 전체 구조 리팩터링은 포함하지 않습니다.
공항 출발/도착 설정의 기존 경로 초기화 동작은 유지합니다.

## 검증
JS 구문 및 경로 fallback·고도 라벨 동기화·자기편차 실패의 로직 회귀 검증을 수행합니다.
실기기 Safari/Android 및 온라인 지도 렌더링 검증은 별도로 필요합니다.
