# KoreaVFR_v2.03

## 커스텀 픽스
- 나침반 위 압정 버튼: 파란색 활성 상태에서 지도 탭으로 픽스 생성.
- 픽스 명, 선택 좌표, 반경 NM(기본 0), 하단/상단 ft, 개별 AGL/MSL 설정.
- 저장/삭제/닫기. 저장 전 닫으면 새 임시 핀 취소. 기존 핀 탭으로 재편집.
- 반경 > 0: 주황색 7pt(약 9.33 CSS px) 경계와 70% 투명 채움.
- 양쪽 고도 입력 및 반경 > 0: 기울어진 지도에서 3D 영역. 정면 지도에서는 2D 원만 표시.
- AGL은 원 둘레 DEM을 기준으로 계산. DEM 미확인 또는 환산 상하한 역전 시 3D 표시 보류.
- 저장된 핀을 500ms 길게 누르고 드래그하면 이동. 범위/3D 영역도 이동.
- 메모리 임시 저장만 지원. 새로고침하면 픽스가 삭제됩니다.

## 배포
ZIP의 index.html, assets, README.md를 GitHub 저장소 루트에 업로드합니다. 별도 빌드는 없습니다.

## 검증 범위
JS 구문과 원 좌표·고도 입력 검증 로직을 검사했습니다.
실제 Safari/Android 길게 누르기 및 WebGL 3D 렌더링은 실기기 확인이 필요합니다.
기존 경로·SIM 기능은 유지합니다. 외부 지도 및 DEM은 네트워크에 의존합니다.
