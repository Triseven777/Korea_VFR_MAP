# KoreaVFR_v2.06

- 픽스 버튼 활성화 시 화면 중앙 고정 압정·빨간 X·FIX설정하기 버튼 표시.
- 지도 스크롤로 위치 선택, FIX설정하기 클릭 시 화면 중앙 X 좌표를 map.unproject로 생성.
- 지도 탭 생성은 제거. 위치 선택 중 항공기 자동 추적 일시 중단.
- 원통 고도 범위 내부 커튼은 원통 앞에 그려 주황색에 가려지고, 범위 밖 커튼은 뒤에 복원하여 돌출부 표시.
- 원통 판정은 Mercator 반경 근사, AGL은 커튼 Terrain height map 사용. 동시 클리핑 최대 64개 픽스.
- 임시 메모리 저장 및 기존 팝업 자동 저장 유지.
