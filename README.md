# KoreaVFR_v2.05

- 루트와 연결되거나 화면상 겹치는 픽스 이름을 숨겨 루트 설명을 우선 표시합니다.
- 3D에서 지표 채움은 숨깁니다. 입력 하단~상단 고도만 영역으로 표시하며 지표에는 1pt 윤곽을 유지합니다.
- AGL 하단은 DEM + 입력고도입니다. 1000ft AGL이면 바닥도 지표에서 1000ft 위에 위치합니다.
- 픽스 영역을 루트 커튼 뒤에 합성하여 주황색 면이 커튼에 겹치게 표시합니다.
- 70% 투명도와 메모리 임시 저장은 유지합니다.

ZIP 내용물을 GitHub 루트에 업로드하세요.
구문·계산·라벨 판정 검증은 통과했으며 실제 기기 3D 렌더링은 별도 확인이 필요합니다.
